## Исследование динамики цен на аренду жилья в Москве для обнаружения сезонных и географических закономерностей

### 1.1. Цель исследования

Выявить **сезонные и географические закономерности** изменения стоимости долгосрочной аренды жилья в Москве с применением методов статистического, пространственного и машинного анализа данных, а также определить характеристики объектов недвижимости, связанные с вариацией арендных ставок.

### 1.2. Бизнес-ценность

Проект направлен на повышение обоснованности решений участников рынка долгосрочной аренды жилья в Москве.

| Стейкхолдер | Что получает |
|---|---|
| **Арендодатели** | Понимание сезонных пиков и провалов для выбора оптимального периода сдачи |
| **Арендаторы** | Оценка справедливости запрашиваемой ставки с учётом географии и характеристик объекта |
| **Агентства недвижимости** | Анализ рыночной ситуации по округам и районам |
| **Инвесторы** | Оценка территориальных различий доходности аренды |

### 1.3. Критерии достижения цели

| № | Критерий | Метод проверки |
|---|---|---|
| 1 | Выявление и статистическая проверка различий стоимости аренды между месяцами и сезонами | Kruskal–Wallis, ANOVA, STL-декомпозиция |
| 2 | Выявление и статистическая проверка различий между административными округами | Kruskal–Wallis + post-hoc (Dunn) |
| 3 | Определение характера и силы связи стоимости с расстоянием до центра и метро | Корреляция Спирмена, регрессия |
| 4 | Определение характеристик объекта, статистически связанных с вариацией ставок | Множественная регрессия, Random Forest + feature importance |
| 5 | Сравнение методов анализа и оценка качества моделей | R², AIC, MAPE |
| 6 | Формирование практических выводов и интерактивный дашборд | Dashboard (≥ 5 разрезов) |

## 2. Границы научного исследования

| Тип границ | Содержание |
|---|---|
| **Территориальные** | Город Москва в административных границах, включая районы с пригодными данными |
| **Временные** | Минимум **12 последовательных месяцев**; для устойчивости сезонных выводов — **24–36 месяцев** |
| **Объектные** | Рынок **долгосрочной аренды жилой** недвижимости. Продажа, краткосрочная/посуточная аренда и коммерческая недвижимость не рассматриваются |
| **Факторные** | Временные (месяц, сезон, год), географические (округ, район, расстояние до центра, до метро, до МКАД), объектные (площадь, комнаты, этаж, тип дома) |

### Ограничения исследования

- Открытые данные могут содержать **пропуски, дубликаты, выбросы** и неточные координаты.
- Указанная цена - **запрашиваемая ставка**, а не фактическая цена договора.
- Доступность данных по районам и периодам **неодинакова**, что влияет на статистическую мощность.

## 4. Аналитическая гипотеза

**Основная гипотеза:** стоимость долгосрочной аренды жилья в Москве характеризуется сезонными и географическими различиями и связана с характеристиками объектов недвижимости. Методы статистического, пространственного и машинного анализа позволяют выявить и количественно оценить эти закономерности.

### 4.1. Подгипотезы

| Код | Гипотеза | Ожидаемый результат |
|---|---|---|
| **H1** | Сезонность: стоимость статистически различается между месяцами и сезонами | Пик — август–сентябрь, спад — январь–февраль |
| **H2** | Географические различия: стоимость различается между округами и районами | Центр дороже периферии |
| **H3** | Пространственная зависимость: стоимость связана с расстоянием до центра и метро | Отрицательная связь с расстоянием до центра, положительная — с близостью к метро |
| **H4** | Влияние характеристик объекта: площадь, комнаты, тип дома, этаж связаны с вариацией ставок | Значимые коэффициенты в регрессии |
| **H5** | Совместное влияние факторов объясняет часть вариации и позволяет прогнозировать ставки | R² > 0,5; MAPE ≤ 15% |

### 4.2. Методы проверки

| Гипотеза | Методы |
|---|---|
| H1 | Kruskal–Wallis, ANOVA, сезонная декомпозиция (STL) |
| H2 | Kruskal–Wallis + post-hoc (Dunn), ANOVA |
| H3 | Корреляция Спирмена, регрессия, гео-визуализация |
| H4 | Множественная регрессия, Random Forest + feature importance |
| H5 | Gradient Boosting, сравнение R² / MAPE, SHAP |

### 4.3. Метрики и уровень значимости

- Уровень значимости: **α = 0,05**
- Доверительные интервалы — для оценки неопределённости
- Метрики качества моделей: **R²**, **AIC**, **MAPE**

---

## 5. Ожидаемые результаты

- Статистические выводы по каждой подгипотезе (H1–H5)
- Визуализации: сезонные ряды, карты округов, heatmap плотности, feature importance
- Интерактивный аналитический дашборд **(≥ 5 разрезов)**
- Практические рекомендации для арендодателей, арендаторов и агентств

## 6. Подбор источников данных и аналитический портрет (п. 2.2)

В соответствии с требованиями п. 3 методических указаний, для исследования подобраны четыре типа открытых источников данных. Все источники охватывают как предмет исследования (аренда жилья), так и факторы влияния (география, транспорт, характеристики объекта), и содержат не менее 3 категориальных и 3 числовых признаков, а также характеристику времени.

### 6.1. Реляционный набор данных (п. 3.1)

**Источник:** [CIAN Parser](https://github.com/NoNanoMax/cian-parser)  
**Формат:** CSV / SQLite  
**Объект:** объявления о долгосрочной аренде квартир в Москве.

**Числовые характеристики:** `price_per_month` (стоимость аренды), `total_meters` (общая площадь), `living_meters` (жилая площадь), `kitchen_meters` (площадь кухни), `rooms_count` (комнат), `floor` (этаж), `floors_count` (этажей в доме), `year_construction` (год постройки).  
**Категориальные характеристики:** `district` (район), `house_material_type` (тип дома), `author_type` (тип арендодателя), `metro` (станция метро).  
**Временная характеристика:** `first_seen_at` / `last_seen_at` (дата появления), `recorded_at` (дата фиксации цены).

### 6.2. Иерархический набор данных (XML) (п. 3.2)

**Источник:** [Yandex Realty Language (YRL)](https://yandex.ru/support/realty/ru/feed/requirements-sale-housing)  
**Формат:** XML-фид  
**Объект:** структурированные объявления о недвижимости.

**Числовые характеристики:** цена (`<price><value>`), общая площадь (`<area><value>`), комнаты (`<rooms>`), этаж (`<floor>`), минут до метро (`<metro><time-on-foot>`), км до МКАД (`<distance>`).  
**Категориальные характеристики:** тип сделки (`<type>`), категория (`<category>`), район (`<location><sub-locality-name>`), метро (`<metro><name>`), тип дома (`<building-type>`), тип продавца (`<sales-agent><category>`).  
**Временная характеристика:** дата создания (`<creation-date>`).

### 6.3. Источник с API (JSON) (п. 3.3)

**Источник:** [RentScout](https://github.com/QuadDarv1ne/rentscout)  
**Формат:** REST API (JSON)  
**Объект:** агрегированные данные об аренде с Avito, Cian, Domofond, Yandex Realty.

**Числовые характеристики:** цена, площадь, комнаты, координаты (широта/долгота), расстояние до точки.  
**Категориальные характеристики:** тип жилья, район, станция метро, источник (площадка).  
**Временная характеристика:** дата публикации (в `/api/ml/trends`).

**Используемые эндпоинты:**
- `GET /api/properties` — цена, комнаты, площадь, адрес, метро.
- `GET /api/geo/heatmap` — район, плотность объектов.
- `POST /api/geo/nearby` — координаты, расстояние.
- `GET /api/ml/trends` — цена, дата, динамика.

### 6.4. Неструктурированные данные (п. 3.4)

**Источники:** 
1. [РБК Недвижимость](https://rbcrealty.ru/news/6aaa52c734a55ae7286e0bf3)
2. [Аналитика Incom](https://www.incom.ru/novosti-i-analitika/novosti-rynka/vysokiy-sezon-na-rynke-arendy-moskvy-rasshiril-ekspozitsiyu-na-12-5-i-uvelichil-spros-na-27/)
**Формат:** Текст (HTML-статьи)  
**Объект:** рыночные тренды, медианные ставки, аналитические сводки.

**Числовые характеристики:** медианная ставка (руб./мес), процент изменения к предыдущему периоду, объем предложения (экспозиция), уровень спроса.  
**Категориальные характеристики:** тип квартиры (студия/1/2/3-комн.), направление тренда (рост/падение/стагнация), сезон (высокий/низкий), сегмент рынка.  
**Временная характеристика:** дата публикации статьи.
